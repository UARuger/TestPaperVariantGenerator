# Генератор варіантів контрольної роботи

## Опис проєкту

Консольна програма мовою C++ для автоматичного створення варіантів контрольної роботи на основі банку завдань із текстового файлу. Користувач може самостійно вказати кількість варіантів і кількість завдань у кожному варіанті. Завдання обираються випадково, без повторень усередині одного варіанта. Між різними варіантами повторення дозволені.

## Можливості

- Завантаження завдань із текстового файлу.
- Перевірка наявності завдань у банку.
- Введення кількості варіантів та завдань.
- Перевірка параметрів генерації.
- Випадковий вибір завдань.
- Виведення результатів у консоль.

## Використані технології

- Мова програмування: C++17.
- Система збирання: CMake.
- Стандартні бібліотеки C++.

**Призначення основних файлів:**

- `src/main.cpp` — головний цикл програми та обробка команд користувача.
- `src/Interface.cpp` — консольний інтерфейс, введення та виведення інформації.
- `src/TaskGenerator.cpp` — завантаження банку завдань, перевірка параметрів і генерація варіантів.
- `data/tasks.txt` — текстовий файл із завданнями.

## Збирання та запуск

Для збирання необхідні компілятор із підтримкою C++17 (GCC, Clang або MSVC) та CMake.

## Linux

Перейдіть у кореневу директорію проєкту та виконайте:

```bash
cmake -S . -B build
cmake --build build
```

Після успішного збирання запустіть виконуваний файл із директорії проєкту:

```bash
./build/TestPaperVariantGenerator
```

**Примітка:** назва виконуваного файлу залежить від `add_executable()` у `CMakeLists.txt`. Запускати програму необхідно з кореневої директорії проєкту, оскільки вона використовує відносний шлях `data/tasks.txt`.

## Використання

Після запуску програма відображає меню:

```text
=== Task Generator ===
0. Exit
1. Generate variants
2. Load tasks from file
======================
```

1. Виберіть пункт `2`, щоб завантажити завдання з `data/tasks.txt`.
2. Виберіть пункт `1`, щоб розпочати генерацію.
3. Введіть кількість варіантів і кількість завдань у кожному.
4. Перегляньте згенеровані варіанти в консолі.
5. Виберіть `0`, щоб завершити роботу.

### Приклад банку завдань

Файл `data/tasks.txt`:

```text
Обчисліть значення виразу: 125 + 378 - 246.
Обчисліть: (48 + 72) / 6 * 3.
Розв'яжіть рівняння: 5x + 12 = 47.
Розв'яжіть рівняння: 3(x - 4) = 2x + 7.
Знайдіть 15% від числа 840.
Ціна товару становила 1200 грн. Після знижки 20% визначте нову ціну.
Знайдіть найменше спільне кратне чисел 18 і 24.
Спростіть вираз: 4(2a - 3) + 5a.
Обчисліть: 3/4 + 5/8.
Знайдіть площу прямокутника зі сторонами 12 см і 7 см.
Знайдіть периметр трикутника зі сторонами 8 см, 11 см і 13 см.
Обчисліть площу круга радіусом 5 см (π = 3,14).
Знайдіть гіпотенузу прямокутного трикутника з катетами 6 см і 8 см.
Розв'яжіть квадратне рівняння: x² - 7x + 12 = 0.
Знайдіть середнє арифметичне чисел 12, 18, 25, 35 і 40.
Автомобіль рухався зі швидкістю 72 км/год протягом 2,5 години. Яку відстань він подолав?
```

Кожен непорожній рядок файлу вважається окремим завданням.

### Приклад генерації

```text
Enter the number of variants to generate: 2
Enter the number of tasks per variant: 3

Variant 1:
Знайдіть найменше спільне кратне чисел 18 і 24.
Знайдіть середнє арифметичне чисел 12, 18, 25, 35 і 40.
Обчисліть: 3/4 + 5/8.

Variant 2:
Знайдіть периметр трикутника зі сторонами 8 см, 11 см і 13 см.
Автомобіль рухався зі швидкістю 72 км/год протягом 2,5 години. Яку відстань він подолав?
Знайдіть гіпотенузу прямокутного трикутника з катетами 6 см і 8 см.
```

Результат випадковий і може відрізнятися під час кожного запуску.

## Обмеження

- Кількість варіантів і завдань повинна бути додатною.
- Кількість завдань в одному варіанті не може перевищувати кількість завдань у банку.
- Перед генерацією необхідно завантажити банк завдань.
- Програма не перевіряє однаковість тексту різних рядків у файлі.
- У поточній версії результати виводяться лише в консоль.
